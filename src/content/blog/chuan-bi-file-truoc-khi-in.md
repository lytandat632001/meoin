Một file thiết kế chuẩn giúp quá trình in diễn ra nhanh chóng và sản phẩm đẹp như mong đợi. Dưới đây là những lưu ý quan trọng khi chuẩn bị file.

## 1. Độ phân giải

- **Ảnh trong file in:** tối thiểu **300 DPI** ở kích thước thực
- **Ảnh 72 DPI (web):** sẽ bị vỡ khi in → không dùng
- **Vector (AI, PDF):** không bị vỡ ở mọi kích thước

## 2. Hệ màu

- **CMYK** cho in offset
- **RGB** sẽ bị lệch màu khi in → cần convert trước
- **Pantone** cho màu đặc biệt, chính xác cao

## 3. Vùng tràn lề (bleed)

- Thêm **2-3mm** viền ngoài thiết kế
- Tránh để chữ/nội dung quan trọng sát mép
- Vùng an toàn: cách mép ít nhất **3-5mm**

## 4. Font chữ

- **Convert font thành outline** (Create Outlines / Convert to Curves)
- Hoặc **nhúng font** vào file (embed fonts)
- Tránh dùng font lạ không có trên máy in

## 5. Định dạng file

Ưu tiên theo thứ tự:
1. **AI, PDF** — file vector gốc, tốt nhất
2. **EPS, SVG** — vector, tương thích cao
3. **PSD** — raster nhưng giữ layer
4. **PNG, JPG** — chỉ dùng khi không có lựa chọn khác

## Kết luận

Chuẩn bị file đúng cách tiết kiệm thời gian và tránh phát sinh chi phí. Nếu chưa chắc, hãy gửi file để được kiểm tra trước khi in.
